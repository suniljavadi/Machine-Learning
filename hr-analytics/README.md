 # HR Analytics

**Status: Learning project**

Notebook-based exploratory analysis of HR data using the included `people.csv` dataset. The project demonstrates data loading, exploratory analysis, visual interpretation, and introductory analytics workflows.

## Contents

- `hr-analytics.ipynb` — analysis notebook
- `people.csv` — sample input data
- `hr-analytics-report.pdf` — exported notebook/report artifact

## Explore

Open the notebook in Jupyter or VS Code with a Python environment containing the packages imported by the notebook. Results and conclusions should be interpreted as educational analysis, not verified workforce metrics.
