# Machine Learning and Data Analysis Practice

**Status: Learning project**

A collection of notebooks and datasets for exploratory data analysis, feature preparation, and introductory machine-learning exercises. The repository is organized by topic rather than as one deployable application.

## Projects

| Directory | Focus | Included material |
| --- | --- | --- |
| `hr-analytics/` | HR data exploration and analysis | Notebook and `people.csv` |
| `netflix-recommendation-analysis/` | Recommendation-oriented analysis | Notebook and movie data |
| `purchase-case-study/` | Purchase behavior analysis | Notebook and purchase data |
| `walmart-sales-analysis/` | Sales analysis | Notebook and Walmart data |
| `covid-19-analysis/` | COVID-19 trend analysis | Notebook and CSV data |
| `pandas-data-analysis/` | Data manipulation practice | Two notebooks and tabular data |
| `numpy-foundations/` | Numerical-computing foundations | Notebook |

## How To Explore

Open the notebooks in Jupyter Notebook, JupyterLab, or VS Code. The repository does not provide a shared `requirements.txt`, test suite, or single application entry point. Install the packages required by each notebook in its own environment.

## Skills Demonstrated

- Python notebook workflows
- NumPy and Pandas data manipulation
- Exploratory analysis and visualization
- Working with CSV datasets
- Introductory recommendation and analytical problem framing

## Limitations

This is a learning collection, not a production ML service. Model selection, preprocessing, validation, metrics, and dataset documentation vary by notebook and should be reviewed in the individual project folders.

## Future Improvements

- Add per-project READMEs with dataset provenance, preprocessing, metrics, and limitations.
- Add reproducible environments and notebook execution checks.
- Separate reusable analysis code from presentation notebooks.
